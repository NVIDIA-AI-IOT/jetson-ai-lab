Tau is an open-source agentic AI companion designed around a continuous conversation rather than isolated chat sessions. It combines immediate and long-term memory with speech recognition, text-to-speech, visual perception, and autonomous awareness.

The project includes support for running a local LLM and speech-to-text on Jetson Orin Nano, with an event-driven architecture for connecting conversational, memory, speech, and vision services.

### Features

- Continuous voice conversation with ongoing context
- Immediate summaries and vector-based long-term memory
- Local LLM and speech recognition on Jetson Orin Nano
- Visual perception and face recognition services
- Event-driven service architecture
